# CuHalide Atlas UX audit — 2026-08-24

This change set is a user-experience and runtime-quality pass over the Current Curated rev.7 review portal. It does not change scientific denominators, the Frozen Release 3.0.2 snapshot, the Structured Photophysics 1.3.0 publication policy, or the public/private data boundary.

## User-facing improvements

- Portal-wide search across curated literature and the Core-Included structure register, available from the header, hero, `Ctrl/Cmd+K`, and `/` keyboard shortcut.
- Guided home-page research paths for Literature, Structures, Photophysics, and the Research Assistant.
- Explicit prepublication-review context in the header.
- Clearer hero copy that reflects the full product: literature, structures, motifs, structured photophysics, and evidence-grounded conversational retrieval.
- Stronger article-card affordance with an explicit `View record` action.
- Standalone/copyable record links inside interactive article and structure dialogs.
- SPA `aria-current` synchronization and a live route announcer for assistive technology.
- Mobile search is full-screen and keyboard/focus managed; all new layouts are covered by overflow and WCAG AA checks.
- Standalone record-page navigation now includes Photophysics and the Research Assistant.

## Runtime corrections

`api/record-current.js` no longer touches Vercel's legacy `req.query` convenience property. Record parameters are parsed from `req.url` with the WHATWG `URL` API, eliminating the only production runtime error cluster observed during the 24-hour audit window (`DEP0169 url.parse()` deprecation warning on `/api/record-current`).

A post-deployment audit also found that the Research Assistant's structured-photophysics sub-route still advertised and queried the earlier two-pass-only contract even though the public portal had already moved to Structured Photophysics 1.3.0. The live Supabase assistant chain was therefore aligned to the same staged publication policy used by `/api/public-data`:

- `cuhalide-atlas-current-rag-r7-science-exact-internal` v3: queries `cuhalide_atlas_public_photophysics_query_v2`, reports contract 1.3.0, and keeps `pass_a_curated` versus `two_pass_verified` explicit per result.
- `cuhalide-atlas-current-rag-r7-unified-internal` v4: propagates the 1.3.0 contract through exact and hybrid Current Curated retrieval.
- `cuhalide-atlas-smart-rag-v302-current-public` v9: uses canonical Public Data v3, exposes staged-photophysics health, and preserves fail-closed/private-evidence checks.
- `cuhalide-atlas-runtime-contract-v1-public` v16: reports Public Data 2.16.0, Metadata 50.4 and Structured Photophysics 1.3.0 with the staged publication gate rather than a two-pass-only gate.

The public assistant health contract is now numerically aligned with the portal: 383/383 Pass A complete, 275 Pass A curated, 54 two-pass verified, 54 verified-no-data, 940 public samples, 2,260 measurements, 2,978 normalized values, 476 mechanism claims and 281 analysis-eligible values.

## Boundaries preserved

- Search uses only `/api/public-data` query-and-view actions.
- No `/api/export` or private/internal schema access is introduced.
- Primary PDF/SI/CIF files, raw evidence locators, internal sample IDs, candidate scores/reason codes and unpublished adjudication remain private.
- Pass A curated and two-pass verified remain distinct in both the portal and Research Assistant.
- Measurement conflicts and ineligible measurements remain fail-closed.
- Frozen Release 3.0.2 remains immutable and is used only for explicit historical-snapshot questions.

## Acceptance gates

- Repository contracts and production deployment gate.
- Existing rev.7 / photophysics / RAG / privacy browser regression suite.
- Dedicated portal UX tests for search, keyboard behavior, record sharing, route semantics and mobile overflow.
- Research Assistant staged-photophysics tests covering both a Pass A-only record (Record 46) and a two-pass record (Record 381), including privacy-field exclusion.
- WCAG AA automated checks, including the open search dialog.
- Lighthouse mobile and desktop performance/accessibility/best-practice/SEO gates.
