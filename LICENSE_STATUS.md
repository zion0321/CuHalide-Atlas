# License status

No top-level open-source or open-data license had been approved when CuHalide Atlas release 3.0.1 was archived. This repository therefore does not assign a new license on behalf of the rights holder.

Before permanent DOI deposition, the repository owner must review and approve licenses appropriate to:

- original software and workflow code;
- original curated database fields and documentation;
- third-party bibliographic metadata;
- figures and other potentially copyrighted material.

Primary articles, supporting information and CIF files are not redistributed in the release package. Absence of a declared license must not be interpreted as permission to reuse or redistribute copyrighted third-party content.

The release archive uses `NOASSERTION` in machine-readable deposition metadata until the owner completes this review.
